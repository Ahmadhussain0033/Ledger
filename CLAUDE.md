# Repo notes for Claude

- **Git workflow:** commit and push directly to `main`. Do not create side branches or pull requests unless asked.
- **No invented data.** Every number, name, project, video and supporter comes from a live source (`js/sources.js`, browser) or the "Sync ledger" Action (`scripts/sync.mjs` → `data/snapshot.json`). `ledger.config.js` holds account names only; `data/manual.json` holds direct entries (cash/transfers) the owner provides.
- **Totals math lives in one place:** `LedgerSources.summarize()` in `js/sources.js`. The site and the README generator both call it.
- **README.md is generated** by `scripts/readme.mjs` (cards in `docs/readme/`, dark + light). Don't hand-edit it; change the generator. It is about the owner's content, not the code. Code/setup docs live in `docs/SETUP.md`.
- **Style:** dark by default, grayscale plus semantic green/yellow/red only (live/synced/error, funded/paused/closed, heatmap). Tokens are in `styles.css`. Click flair is a light burst + press-in with no overshoot or wobble.
- **Every section always renders on the site.** With no data it shows a plain empty state. The README only shows sections that have something in them. Never add a preview mode or example accounts. Only add entries the owner asks for, in `data/manual.json`. Never invent receipt files; a receipt can be a short note like "personal".
- **Minimalism:** sections are quiet row lists (date · title · meta · value), not stacks of cards or stat grids. Records are searched in the on-page **Search** section (filter chips, sort, receipt links on every expense). <kbd>/</kbd> and ⌘K search the *site* (sections, projects, links, actions) only. Never add per-section search boxes; link to the Search section with `data-search="<type>"`.
- **Not a portfolio:** don't show repos, pinned repos, contribution heatmaps or GitHub stats anywhere (site or README).
- **Icons/fonts:** use `icon("name")` / `icon("brand:slug")` from `js/icons.js` (generated by `scripts/build-icons.mjs` from Lucide + Simple Icons). Font pairings live in `FONTS` in `js/app.js`; Geist is the default.
- **Privacy:** never publish emails; anonymous/private supporters stay unnamed; Patreon names are opt-in.
